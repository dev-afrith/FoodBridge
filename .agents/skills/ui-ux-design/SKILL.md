# UI/UX Design Skill

## Goal
Create high‑fidelity design assets and documentation that define the visual language, interaction patterns, and overall user journey for FoodBridge.

## Scope
- Conduct stakeholder interviews and competitor analysis.
- Produce user personas, journey maps, and sitemap.
- Design wireframes and high‑fidelity mockups in Figma.
- Define UI component library (colors, typography, icons, spacing).
- Specify interaction flows and micro‑copy.
- Deliver a design handoff package (design system JSON, style guide PDF, assets).

## Actionable Steps
1. **Research** – Gather business goals, target audience, and brand guidelines.
2. **Persona Creation** – Write 2‑3 concise personas with pain points and goals.
3. **User Flow Mapping** – Sketch primary flows (home, browse meals, checkout, account).
4. **Sitemap** – List all top‑level pages and relationships.
5. **Wireframes** – Low‑fidelity layouts for each key page in Figma.
6. **Design System** – Define:
   - Primary/secondary color palette.
   - Typography scale (font families, sizes, line‑height).
   - UI components (buttons, cards, forms, modals).
   - Icon set conventions.
7. **High‑Fidelity Mockups** – Apply the design system to create polished screens.
8. **Accessibility Review** – Run contrast checks, ensure keyboard focus order.
9. **Documentation** – Export style guide PDF and JSON for developers.
10. **Hand‑off** – Share Figma link, assets folder, and design system JSON with the frontend team.

## Deliverables
- Persona document (`personas.md`).
- User flow diagrams (`flows.mermaid`).
- Sitemap (`sitemap.md`).
- Wireframe frames in Figma.
- Design system JSON (`design-system.json`).
- High‑fidelity mockup PDFs.
- Accessibility audit checklist.

## Usage
Run this skill when the project moves from concept to visual design. The output files should be placed under `docs/design/`.
