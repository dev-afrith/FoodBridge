# FoodBridge 🌱
### Turning Surplus Into Smiles

FoodBridge is a social-impact web platform designed to connect food donors with people and communities in need. Its goal is to reduce food waste, encourage responsible food donation, and make surplus food redistribution easier.

Instead of letting excess food go to waste, FoodBridge promotes a simple idea: **surplus food can become someone's next meal.**

---

## 🌍 The Problem

Large quantities of edible food are wasted every day, while many people struggle to access nutritious meals.

FoodBridge aims to help bridge this gap by making food donation and redistribution more accessible.

## 💡 Our Solution

FoodBridge provides a user-friendly platform concept where individuals, restaurants, organisations, and other donors can submit surplus food donation details.

The platform demonstrates how food donation information can be organised to support redistribution.

## ✨ Key Features

- **Food Donation Form** – Submit surplus food details.
- **Flexible Food Categories** – Enter multiple food items.
- **Dietary Classification** – Vegetarian, vegan, egg, and non-vegetarian options.
- **Location Details** – Enter a city, town, or village.
- **Impact Calculator** – Explore estimated meals and environmental impact.
- **Donation Confirmation** – View a demonstration submission confirmation.
- **Responsive Design** – Designed for desktop, tablet, and mobile devices.
- **Interactive UI** – Smooth animations and engaging user interactions.

> **Note:** FoodBridge is currently a demonstration project. Submitting the form does not schedule an actual food pickup or guarantee food redistribution.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/dev-afrith/FoodBridge.git
```

### 2. Navigate to the frontend

```bash
cd FoodBridge/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Create a production build

```bash
npm run build
```

## 🇮🇳 Our Mission

FoodBridge envisions a community where surplus food is treated as a resource rather than waste.

Our mission is to encourage food donation, reduce avoidable food waste, and promote a culture of sharing.

## ⚠️ Disclaimer

FoodBridge is a prototype created for demonstration and educational purposes. Impact calculations are illustrative estimates, not verified outcomes. The project does not currently provide real-time donor verification, food collection, delivery, or redistribution services.
